# Airic Spec

**Document-Centric Agent Runtime Model**

Airic is an open specification for document-driven human–AI collaboration.
It defines how agents, workflows, and context are expressed as *executable documents* — forming a self-describing, recursively extensible architecture for AI-native work.

- Everything is a document.
- Documents define and drive agents.
- Agents execute and write back into the same documents.
- The system describes itself, recursively.

This repository hosts the **Airic Spec v0.2**, examples, and related references.

## Why

Today’s AI agents are powerful but fragile — context transfer and structure loss limit real productivity.  
Airic formalizes a new model where documents *are* the runtime: the shared substrate for context, execution, and governance.
